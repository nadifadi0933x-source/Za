# آنیمه‌پلاس - پلتفرم استریم انیمه، مانگا و مانها

پلتفرم پیشرفته استریم انیمه، خواندن مانگا و مانها با پشتیبانی کامل از زبان فارسی و راست‌به‌چپ.

## ویژگی‌ها

- 🎬 پخش ویدیوی آنیمه با کیفیت‌های مختلف
- 📖 خواندن مانگا و مانها با قابلیت زوم و ناوبری
- 🔍 جستجو پیشرفته با فیلترهای متنوع
- ⭐ سیستم امتیازدهی و نظرات
- ❤️ علاقه‌مندی‌ها و تاریخچه تماشا
- 📱 طراحی واکنش‌گرا و موبایل‌فریندلی
- 🌙 پشتیبانی از تم تاریک و روشن
- 👤 پنل کاربری و مدیریت پروفایل
- 🛡️ پنل مدیریت کامل برای مدیران
- 📊 آمار و تحلیل‌های پیشرفته

## تکنولوژی‌ها

- **React 19** - کتابخانه رابط کاربری
- **Tailwind CSS v3** - استایل‌دهی با پشتیبانی RTL
- **React Router v6** - مسیریابی
- **React Query (TanStack Query)** - مدیریت وضعیت سرور
- **Framer Motion** - انیمیشن‌ها
- **Zustand** - مدیریت وضعیت کلاینت

## نصب و راه‌اندازی

```bash
git clone https://github.com/username/anime-plus.git
cd anime-plus
npm install
npm run dev
```

## ساختار پروژه

```
frontend/
├── src/
│   ├── components/
│   │   ├── Common/        # کامپوننت‌های مشترک
│   │   ├── Layout/        # چیدمان‌های صفحه
│   │   ├── Auth/          # فرم‌های احراز هویت
│   │   ├── Content/       # کامپوننت‌های محتوا
│   │   ├── Player/        # پخش ویدیو
│   │   ├── Reader/        # خواندن مانگا
│   │   ├── User/          # صفحات کاربر
│   │   ├── Admin/         # پنل مدیریت
│   │   └── Shared/        # کامپوننت‌های مشترک
│   ├── pages/             # صفحات اصلی
│   ├── store/             # استورهای Zustand
│   ├── hooks/             # هوک‌های سفارشی
│   └── utils/             # ابزارهای کمکی
```
